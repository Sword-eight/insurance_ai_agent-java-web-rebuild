# Phase 9.5 Interview

## 1. 为什么 Vue 不能直接调用 Python？

Java 是用户鉴权、资源归属、MySQL 事实、Redis 保护和稳定错误的唯一业务入口。绕过 Java 会
绕过 JWT、幂等与消息状态，并把内部 Python 契约暴露给浏览器。

## 2. 为什么使用一个 `ApiResponse<T>` 泛型？

它复用稳定外层字段，同时保留每个 `data` 的独立静态类型。统一外层不等于把所有响应写成
`any`；否则字段漂移只能在运行时发现。

## 3. 请求拦截器和响应拦截器分别负责什么？

请求侧集中附加 Bearer JWT；响应侧只处理横切行为，例如 401 清理与统一错误转换。业务页面
仍决定怎样显示特定错误，拦截器不能吞掉异常。

## 4. 前端路由守卫是不是安全边界？

不是。守卫只避免未登录用户看到无意义页面，可被绕过。真正的身份验证和资源归属必须由
Java SecurityFilterChain 与 Service 完成。

## 5. 为什么选择 `sessionStorage`？

它满足极简跨页面状态并在标签页关闭后清除，暴露窗口短于长期存储。代价是仍可受 XSS 影响，
因此不能记录 Token，也不能把客户端状态视为可信身份。

## 6. 禁用发送按钮后为什么还要幂等键？

按钮只能阻止当前 UI 的机械双击，无法覆盖多标签、网络重放或客户端重复请求。数据库唯一约束
和 Java 幂等逻辑才是最终防线。

## 7. 504/UNKNOWN 为什么不能自动重试？

读取超时不代表 Python 没有执行；自动重试可能再次调用 LLM/Tool 并写重复消息。客户端只展示
“结果暂时无法确认”，后续处理由 Java 契约决定。

## 8. 为什么成功聊天后重新查询历史？

MySQL/Java 是消息事实来源。重新查询避免客户端长期维护第二套消息状态；若查询短暂失败，才
临时展示刚收到的真实响应。

## 9. 为什么开发环境使用 Vite proxy？

浏览器继续请求同源 `/api`，Vite 只在开发时转发 Java，避免为本地前端扩大 Java CORS 面。
生产环境由同源反向代理承担相同路径路由。

## 10. 为什么本阶段不引入 Pinia 和 Element Plus？

状态和组件数量仍很小，组合式模块与原生组件已足够。额外框架会增加学习面、包体和抽象成本，
真实复杂度出现后再评审更符合 YAGNI。
