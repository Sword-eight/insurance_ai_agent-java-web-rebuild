# Phase 10 Interview Questions

## 1. 为什么 Java 与 Python 之间不用共享文件路径？

共享路径会耦合部署拓扑、操作系统、挂载和权限。流式 multipart 让 HTTP 契约自包含，服务可独立部署。

## 2. 为什么扩展名和 MIME 都通过了还要检查 `%PDF-`？

扩展名和 MIME 都可由客户端伪造。文件签名提供内容层最低门槛，但仍不等价于杀毒或完整 PDF 解析验证。

## 3. 为什么文件名不能直接用于落盘？

文件名可包含路径片段、特殊字符或冲突名。随机 UUID 存储键阻断路径穿越和覆盖，原名只作展示。

## 4. 为什么调用 Python 时不能保持 MySQL 事务？

远程调用耗时和失败不可控，长事务会占连接和锁，扩大故障范围。状态机配合短事务更能表达跨资源结果。

## 5. `FAILED` 和 `UNKNOWN` 有什么区别？

`FAILED` 表示收到确定失败；`UNKNOWN` 表示没有可信终态，Python 可能已成功。后者不能自动重试。

## 6. 不使用分布式事务如何保证一致性？

不承诺瞬时强一致，而是用受控补偿、显式状态、幂等身份和可重建派生物实现可解释的最终状态。

## 7. FAISS 重建为什么不能先删除旧索引？

删除后再构建会产生不可用窗口，构建失败还会丢失服务能力。候选构建加原子发布保证旧版持续可用。

## 8. `RLock` 能解决多实例并发吗？

不能。它只保护单进程内线程；多实例需要外部协调或单写者架构，必须另行评审。

## 9. 为什么 Python 还要重复计算 SHA-256？

它验证传输内容与 Java 声明一致，也把内部 HTTP 边界当成不可信输入，避免损坏或绕过。

## 10. 为什么跨用户文档返回 404 而不是 403？

统一 404 可避免攻击者通过响应差异枚举其他用户资源，同时本人资源仍由 `userId + documentId` 查询授权。
