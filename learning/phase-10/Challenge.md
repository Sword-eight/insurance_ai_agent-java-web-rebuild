# Phase 10 Challenges

## 1. 文件校验攻击面

构造以下 multipart 请求并写出预期 HTTP 状态、数据库行数和 Python 调用次数：空文件、伪造 MIME、
正确 MIME 但错误签名、20 MiB + 1 byte、文件名包含 `../`。

## 2. 状态机推演

分别在原文件移动、首次 INSERT、`INDEXING` 更新、Python 建索引和最终 `INDEXED` 更新处注入失败，说明
哪些事实应该保留、哪些可以补偿，以及最终状态是否可确定。

## 3. 原子发布实验

让候选索引构建到一半抛出异常，同时连续执行检索。验证 current marker 没有改变、旧内存索引仍可读、
候选目录被清理。

## 4. 多实例设计题

假设 Python 扩容到三个实例，说明进程内锁为什么不足，并比较“单写者”“外部锁”“版本化对象存储”三种
演进方案；只做设计，不在当前 Phase 实现。

## 5. 恢复流程设计

为 `UNKNOWN` 设计一个显式、可审计且幂等的人工重建流程。要求不能自动重发，也不能把 Java 原文件路径
暴露给 Python。
